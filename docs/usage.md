# 使用与设置

[← 文档首页](README.md)

## 常用操作

| 操作 | 效果 |
| --- | --- |
| 悬停词岛 | 展开歌曲信息、播放按钮和进度条 |
| 双击歌词区域 | 播放 / 暂停 |
| 点击或拖动进度条 | 跳转播放位置；需要可用的歌曲总时长 |
| 展开后滚动 | 开启“鼠标滚轮调节音量”后，每格调节 2% 的 SPW 音量 |
| 点击或拖动音量条 | 调节 SPW 音量 |
| 拖动词岛 | 调整位置，靠近边缘或中心线时吸附 |
| 右击词岛 / 托盘 | 打开快捷菜单；Linux 使用托盘 |
| `Ctrl+Shift+D` | 在 SPW 内显示 / 隐藏词岛；需快捷键权限，可在 SPW 中修改或配置全局绑定 |
| 插件设置 → “找回词岛” | 显示词岛、解除鼠标穿透并移回主屏幕顶部 |
| 插件设置 → “重置设置” | 恢复所有默认设置，包括字体和位置 |

完整设置在 SPW 插件设置页；“关于与状态”可查看运行状态。重置后若数值未刷新，重新打开设置页。

## 歌词

- **显示翻译**：在主歌词下方显示已有翻译。
- **逐字高亮与长音强调**：使用歌词的逐字时间信息呈现高亮和动效。
- **强制逐字显示**：需开启逐字高亮，为普通 LRC 估算逐字进度；可能与演唱节奏不同，不应用长音发光。
- **逐字高亮偏移 ms**：正值提前，负值延后，适用于整体固定偏差。
- **实验性多行歌词**：同时显示时间重叠的歌词行，异常时可关闭。

## 外观与字体

“外观”支持胶囊和顶部刘海。胶囊可自由拖动；刘海贴住工作区顶部，只能水平拖动。

“最大宽度”限制词岛宽度；开启“固定词岛宽度”后不再随歌词长短收缩。“圆角大小 %”和“背景不透明度”分别调整圆角与透明度。

默认字体为内置 MiSans。Windows 在“歌词字体”窗口选择字体和字形；Linux 填写字体名称并选择字重，名称留空使用 MiSans。字号在插件设置中调整。字体不存在、缺字或缺少指定字重时会尝试回退。

### 液态玻璃（实验性）

在“背景样式”中选择“液态玻璃（实验性）”。Linux 需先[安装配套支持](installation.md#linux)。支持的系统和显示范围见 [兼容性与限制](compatibility.md#液态玻璃)；低性能模式使用经典背景。

## 封面、频谱和配色

“两侧信息”可选择封面与频谱、仅频谱、仅封面或全部隐藏。实时频谱的环境要求见 [兼容性与限制](compatibility.md#实时频谱)。

歌词高亮、背景和频谱可分别使用封面颜色；无封面时使用默认颜色。背景取色仅对经典背景生效。

“背景播放进度样式”支持注水和边缘细线；低性能模式下关闭。

## 位置和播放控制

胶囊按工作区的左 / 中 / 右、上 / 中 / 下吸附。顶部位置向下展开，底部向上展开，中部居中展开。切换显示器后找不到词岛时，使用“找回词岛”。

悬停展开后可切歌、播放 / 暂停及拖动进度条。网络歌曲或不可读文件可能无法取得总时长，此时不能拖动进度。

开启“鼠标滚轮调节音量”后，在展开的词岛上滚动可调节 SPW 音量，范围为 0–100%。滚动后短暂显示音量条，可点击或拖动；停止操作后恢复进度条。穿透或悬停隐藏时不可用。

## 显示与交互

- **鼠标穿透**：将鼠标事件交给下方窗口。可从托盘关闭，或用“找回词岛”恢复操作。
- **鼠标经过时自动隐藏**：移入隐藏、移开恢复，并开启鼠标穿透。Linux 支持 X11、KDE Wayland 和[已安装配套支持](installation.md#linux)的 GNOME Wayland；指针连接失效时保持显示。
- **全屏时隐藏**：仅 Windows；动态壁纸等桌面软件也可能被识别为全屏。
- **暂停时隐藏**：暂停后收起，恢复播放时展开。

低性能模式会降低刷新率、简化动效，使用模拟频谱和经典背景；歌词和基本交互仍可使用。

## 快捷菜单

托盘 / 右键菜单提供显示、穿透、悬停隐藏、低性能模式、找回词岛、重置位置和关于与状态。关闭穿透时会同时关闭悬停隐藏。

遇到异常请查看 [故障排查](troubleshooting.md)。
