# 使用与设置

[← 文档首页](README.md)

安装并启用插件后，播放一首 SPW 已经成功加载歌词的歌曲，词岛就会出现。

## 常用操作

| 操作 | 效果 |
| --- | --- |
| 悬停词岛 | 展开歌曲信息、播放按钮和进度条 |
| 双击歌词区域 | 播放 / 暂停 |
| 点击或拖动进度条 | 跳转播放位置；需要可用的歌曲总时长 |
| 在展开的词岛上滚动 | 开启“鼠标滚轮调节音量”后，调节 SPW 播放器自身音量 |
| 点击或拖动音量条 | 音量条显示期间，按位置调节 SPW 音量；悬停或拖动时保持显示 |
| 拖动词岛 | 调整位置，靠近边缘或中心线时自动吸附 |
| 右击词岛 | 打开快捷设置；Linux 改用托盘菜单 |
| 托盘右键 | 打开常用设置和恢复操作 |
| `Ctrl+Shift+D` | 默认在 SPW 内显示 / 隐藏词岛；需授予快捷键权限，可在 SPW 快捷键管理中修改或配置全局绑定 |
| 插件设置 → “找回词岛” | 恢复显示并移回主屏幕；同时解除鼠标穿透 |
| 插件设置 → “重置设置” | 一次恢复全部默认设置，包括字体和位置；设置页里的数值可能要重新打开才会刷新 |

快捷菜单只放常用项。圆角、最大宽度、透明度、字体、取色等完整设置仍在 SPW 的插件设置页里。

设置页按“显示与交互”“歌词显示”“字体”“外观与布局”“背景与进度”“封面与频谱”和“工具与关于”分组。“找回词岛”在首组，“重置设置”在最后一组底部。

## 歌词

### 翻译

开启“显示翻译”后，有翻译的歌词会在主歌词下方显示第二行。插件不会自己生成翻译。

### 逐字高亮和动效

带逐字时间信息的歌词支持平滑高亮、逐字抬升、长音强调、辉光和切换动效。普通逐行歌词默认按整行显示，过长时会自动平移。

在插件设置中同时开启“逐字高亮”和“强制逐字显示”，可为普通 LRC 按行时长估算逐字进度。此开关默认关闭，Windows 和 Linux 均可用。原生逐字时间轴优先；估算内容不应用长音发光，也不会改写歌词文件。估算进度可能与实际演唱节奏不同。

如果所有歌曲都存在固定的提前或延后，可以调整“逐字高亮偏移 ms”。不同歌曲需要不同偏移时，通常更像歌词源本身的时间轴问题。

### 实验性多行歌词

开启后会尝试保留仍未结束的已播歌词，并在时间重叠时显示多行。它比默认单行模式更依赖宿主歌词信息，遇到异常直接关闭即可，不影响普通歌词显示。

## 外观

“外观”可以选择胶囊或顶部刘海。刘海始终贴住显示器工作区顶部，只能沿顶部水平拖动。

常用外观设置还有：

- “圆角大小 %”：调整轮廓圆润程度；
- “最大宽度”：限制词岛最多能拉多宽；
- “固定词岛宽度”：不再跟随歌词长短收缩；
- “背景不透明度”：调整背景透明程度。

### 液态玻璃（实验性）

在插件设置的“背景样式”中选择“液态玻璃（实验性）”。支持的系统、显示范围和回退条件见 [兼容性与限制](compatibility.md#液态玻璃)。低性能模式使用经典背景。

#### GNOME 配套扩展

GNOME 50 首次启用时，在“背景与进度”中点击“安装 / 修复 Linux 液态玻璃支持”，按照提示重新登录后启用液态玻璃。如果仍未生效，可在“工具与关于”中导出诊断包并参阅 [故障排查](troubleshooting.md#液态玻璃未生效或背景更新慢)。

#### KDE 配套效果

Arch Linux 的 KWin 6.6–6.8 Wayland 提供实验性接入，仍需实机验收。先在同一“安装 / 修复 Linux 液态玻璃支持”入口安装，按系统授权窗口完成原生组件部署，再选择液态玻璃并关闭低性能模式。“关于与状态”应显示“KWin 合成器”；无需终端、注销或额外安装 kwin-effects-glass。

首次安装可能补充本机编译工具。原生组件需要匹配当前 KWin，系统更新后按提示使用同一入口修复；普通着色器更新自动同步。安装器只加载词岛自己的效果，不修改全局模糊设置。低性能模式、隐藏或关闭词岛会停止玻璃桥接并释放背景纹理。

### 字体

Windows 和 Linux 默认歌词均使用内置 MiSans。Windows 字体窗口提供细体、正体、中等、粗体等字形预设；Linux 设置页保留字重选项。

Windows 在插件设置中点击“歌词字体”，即可搜索已安装字体，选择该字体提供的字形并预览词岛；选择“内置 MiSans”可恢复默认字体。字号在 SPW 设置页单独调整。Linux 仍使用字体名称与字重设置项。自定义字体只影响歌词，缺字会先回退到内置 MiSans，再回退到系统字体；所选字型缺失时使用最接近的已有字重。

## 封面、频谱和配色

两侧信息可以选：

- 左侧封面 + 右侧频谱；
- 左侧实时频谱；
- 左侧专辑封面；
- 全部隐藏。

Linux 实时频谱需要 PipeWire 与 `pw-record` / `pw-dump`。暂时找不到 SPW 播放流或缺少工具时改用模拟频谱；“关于与状态”显示当前来源。

封面取色可以分别应用到歌词高亮与长音辉光、背景和频谱。取色会尽量避开近黑和近白区域，所以不一定等同于封面中心像素。背景会使用封面色相生成深色，歌词高亮会生成浅色；两者同时取色时进一步保证对比，背景较透明时歌词会增加细描边。

背景播放进度支持“关闭”“背景注水”和“边缘细线”，低性能模式下关闭动态背景进度。

## 位置和展开方向

胶囊模式拖动时，会按当前显示器工作区的左 / 中 / 右、上 / 中 / 下自动吸附成九宫格锚点。刘海模式固定在工作区顶部，水平拖动时仍可吸附左侧、中心或右侧。

顶部位置向下展开，底部位置把播放控件向上展开，中部使用居中的缩放方式。多显示器变化后找不到词岛时，直接用“找回词岛”。

## 播放控制

悬停展开后可以使用上一首、播放 / 暂停、下一首和进度条。

进度条需要可靠的歌曲总时长。本地音频通常可以读取；网络歌曲或不可读文件可能只能显示当前播放时间，其他播放控制不受影响。

在插件设置中开启“鼠标滚轮调节音量”（默认关闭）后，正常交互模式下悬停展开词岛，在任意区域向上 / 向下滚动，每格增加 / 减少 2% 的 SPW 音量，范围为 0–100%。穿透或悬停自动隐藏模式下不生效。

滚动后进度条会暂时变成音量条，可点击或拖动调节音量；停止操作后恢复播放进度。

此功能适配 SPW 1.19 的内部音量接口；接口不兼容时会提示音量控制不可用，播放控制仍可使用。

## 鼠标交互

### 鼠标穿透

开启后，鼠标事件会直接交给词岛下方窗口。想重新操作词岛，可以从托盘关闭穿透，或者在 SPW 插件设置里点“找回词岛”。

### 悬停自动隐藏

开启后，鼠标移入词岛区域会将其隐藏，移开后恢复；同时自动开启鼠标穿透。低性能模式下不播放过渡动画。

Linux 支持 X11、KDE Wayland 和安装配套扩展的 GNOME Wayland。GNOME 45–50 请先在插件配置点击“安装 GNOME 悬停隐藏支持”，首次安装或更新后保存工作并重新登录。其他 Wayland 桌面或指针连接失效时保持显示。

悬停隐藏期间词岛内容保持常驻，歌词和播放状态继续更新；移开鼠标后直接恢复当前内容。

### 全屏时隐藏

Windows 前台窗口进入全屏时自动隐藏词岛。动态壁纸或覆盖整个屏幕的桌面软件有时也会被识别为全屏。

“暂停时隐藏”在 Windows 和 Linux 都可用。暂停时沿用悬停隐藏的收起动画，恢复播放时反向展开；动画中再次暂停或继续播放会从当前进度平滑衔接。低性能模式下直接隐藏或显示。

## 低性能模式

低性能模式会降低常规刷新率，并简化逐字高亮、动效和部分窗口检查。还会停止实时音频捕获，改用轻量模拟频谱；液态玻璃切换为经典背景。

它不会把所有动画彻底关掉，歌词时间推进和基本交互仍会保留。

## 快捷菜单

托盘 / 右键菜单保留“显示词岛”“鼠标穿透”“悬停隐藏”“低性能模式”四个开关，以及“找回词岛”“重置位置”“关于与状态”三个操作。翻译、逐字高亮、外观和自动隐藏条件等完整设置统一放在 SPW 插件配置页。

悬停隐藏开启时，“鼠标穿透”会显示勾选；从菜单关闭穿透会同时关闭悬停隐藏，以恢复鼠标操作。

“关于与状态”可查看播放、渲染和交互状态；遇到异常时可导出诊断包。

Linux 的快捷设置入口在系统托盘，词岛区域右键暂不提供菜单。

遇到异常可直接看 [故障排查](troubleshooting.md)；想确认某个平台有没有某项能力，看 [兼容性与限制](compatibility.md)。
