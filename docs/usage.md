# 使用与设置

[← 文档首页](README.md)

安装并启用插件后，播放一首 SPW 已经成功加载歌词的歌曲，词岛就会出现。

## 常用操作

| 操作 | 效果 |
| --- | --- |
| 悬停词岛 | 展开歌曲信息、播放按钮和进度条 |
| 双击歌词区域 | 播放 / 暂停 |
| 点击或拖动进度条 | 跳转播放位置；需要可用的歌曲总时长 |
| 拖动词岛 | 调整位置，靠近边缘或中心线时自动吸附 |
| 右击词岛 | 打开快捷设置；Linux 改用托盘菜单 |
| 托盘右键 | 打开常用设置和恢复操作 |
| `Ctrl+Shift+D` | 在 SPW 内显示 / 隐藏词岛，目前不是全局快捷键 |
| 插件设置 → “找回词岛” | 恢复显示并移回主屏幕；Windows 同时解除鼠标穿透 |
| 插件设置 → “重置设置” | 一次恢复全部默认设置，包括字体和位置；设置页里的数值可能要重新打开才会刷新 |

快捷菜单只放常用项。圆角、最大宽度、透明度、字体、取色等完整设置仍在 SPW 的插件设置页里。

Windows 下，插件托盘图标由独立程序提供。可在“设置 → 个性化 → 任务栏 → 其他系统托盘图标”分别选择 SPW 和词岛图标是常驻任务栏，还是收进隐藏图标菜单。若独立托盘程序无法启动，插件会回退到原有托盘模式，此时两个图标可能仍会联动。

## 歌词

### 翻译

开启“显示翻译”后，有翻译的歌词会在主歌词下方显示第二行。插件不会自己生成翻译。

### 逐字高亮和动效

带逐字时间信息的歌词支持平滑高亮、逐字抬升、长音强调、辉光和切换动效。普通逐行歌词仍按整行显示，过长时会自动平移。

如果所有歌曲都存在固定的提前或延后，可以调整“逐字高亮偏移 ms”。不同歌曲需要不同偏移时，通常更像歌词源本身的时间轴问题。

### 实验性多行歌词

开启后会尝试保留仍未结束的已播歌词，并在时间重叠时显示多行。它比默认单行模式更依赖宿主歌词信息，遇到异常直接关闭即可，不影响普通歌词显示。

## 外观

“外观”可以选择胶囊或顶部刘海。刘海始终贴住显示器工作区顶部，只能沿顶部水平拖动。

常用外观设置还有：

- “圆角大小 %”：调整轮廓圆润程度；
- “最大宽度”：限制词岛最多能拉多宽；
- “固定词岛宽度”：不再跟随歌词长短收缩；
- “背景不透明度”：调整背景透明程度。

### 字体

Windows 和 Linux 默认歌词均使用内置 MiSans。Windows 字体窗口提供细体、正体、中等、粗体等字形预设；Linux 设置页保留字重选项。

Windows 在插件设置中点击“歌词字体”，即可搜索已安装字体，选择该字体提供的字形并预览词岛；选择“内置 MiSans”可恢复默认字体。字号在 SPW 设置页单独调整。Linux 仍使用字体名称与字重设置项。自定义字体只影响歌词，缺字会先回退到内置 MiSans，再回退到系统字体；所选字型缺失时使用最接近的已有字重。

## 封面、频谱和配色

Windows 的两侧信息可以选：

- 左侧封面 + 右侧频谱；
- 左侧实时频谱；
- 左侧专辑封面；
- 全部隐藏。

Linux 当前使用本地专辑封面，不提供 SPW 进程实时频谱。

封面取色可以分别应用到歌词高亮与长音辉光、背景和 Windows 实时频谱。取色会尽量避开近黑和近白区域，所以不一定等同于封面中心像素。背景会使用封面色相生成深色，歌词高亮会生成浅色；两者同时取色时进一步保证对比，背景较透明时歌词会增加细描边。

背景播放进度支持“关闭”“背景注水”和“边缘细线”。细线位于胶囊顶部或刘海底部。开始隐藏或展开控件时，背景进度会柔和淡出；隐藏、恢复和控件动画期间暂不显示，动画结束并恢复收起状态后再淡入。关闭背景进度设置也会淡出。低性能模式下会关闭动态背景进度。

## 位置和展开方向

胶囊模式拖动时，会按当前显示器工作区的左 / 中 / 右、上 / 中 / 下自动吸附成九宫格锚点。刘海模式固定在工作区顶部，水平拖动时仍可吸附左侧、中心或右侧。

顶部位置向下展开，底部位置把播放控件向上展开，中部使用居中的缩放方式。多显示器变化后找不到词岛时，直接用“找回词岛”。

## 播放控制

悬停展开后可以使用上一首、播放 / 暂停、下一首和进度条。

控件打开时会略微超过目标大小再柔和回弹，收起时会略微小于收起尺寸再回弹，速度与悬停隐藏 / 恢复一致。可拖动进度条与播放 / 暂停等按钮一起淡入、淡出和移动。低性能模式下直接切换展开或收起状态。

进度条需要可靠的歌曲总时长。本地音频通常可以读取；网络歌曲或不可读文件可能只能显示当前播放时间，其他播放控制不受影响。

## Windows 鼠标交互

### 鼠标穿透

开启后，鼠标事件会直接交给词岛下方窗口。想重新操作词岛，可以从托盘关闭穿透，或者在 SPW 插件设置里点“找回词岛”。

### 悬停自动隐藏

需要先开启鼠标穿透。鼠标进入词岛区域时，刘海顶部连接区域和下方主体一起向左右拉伸，同时压低高度并融入顶部；胶囊先收成圆，再缩小消失。移开后反向恢复，并在末尾柔和回弹一次。低性能模式下直接隐藏或恢复。

悬停隐藏期间词岛内容保持常驻，歌词和播放状态继续更新；移开鼠标后直接恢复当前内容。

### 全屏时隐藏

前台窗口进入全屏时自动隐藏词岛。动态壁纸或覆盖整个屏幕的桌面软件有时也会被识别为全屏。

“暂停时隐藏”则 Windows 和 Linux 都可用。

## 低性能模式

低性能模式会降低常规刷新率，并简化逐字高亮、动效和部分窗口检查。Windows 下还会停止实时音频捕获，改用轻量模拟频谱。

它不会把所有动画彻底关掉，歌词时间推进和基本交互仍会保留。

## 快捷菜单

托盘 / 右键菜单适合临时切换显示、歌词、性能模式和部分交互设置。较低频的项目继续放在 SPW 原生插件配置页里。

Linux 的快捷设置入口在系统托盘，词岛区域右键暂不提供菜单。

遇到异常可直接看 [故障排查](troubleshooting.md)；想确认某个平台有没有某项能力，看 [兼容性与限制](compatibility.md)。
