# 故障排查

[← 文档首页](README.md)

先确认插件已启用、SPW 能显示当前歌曲歌词。找不到词岛时使用“找回词岛”；歌词时序异常时可用本地歌曲、1× 播放和默认单行模式对比。

## 安装与显示

### 插件没有出现在 SPW 插件列表

通过 SPW 插件管理导入 `.spmod`，不要解压后导入内部文件或源码包。确认 SPW 1.19.0+（Workshop API dev23）、Java 25+。详见 [安装与更新](installation.md)。

### 插件启用了，但词岛完全不显示

在插件设置点击“找回词岛”，它会恢复显示、解除穿透并移回主屏幕顶部。再检查“显示词岛”“暂停时隐藏”和 Windows 的“全屏时隐藏”。

`Ctrl+Shift+D` 无反应时，检查快捷键权限及 SPW 中的绑定冲突。

### 词岛突然消失

检查暂停、全屏和悬停隐藏设置。动态壁纸等桌面软件也可能被 Windows 识别为全屏。显示器连接变化后可用“找回词岛”恢复位置。

### 被最大化窗口遮挡，或显示桌面后无法恢复

检查隐藏设置并使用“找回词岛”。仍异常时，请附截图或录屏、诊断包，以及是否使用了 `Win+D`。

### 开启鼠标穿透后无法操作词岛

从托盘关闭穿透，或在 SPW 插件设置中点击“找回词岛”。

## 歌词与时序

### 只有歌名，没有歌词

确认 SPW 已加载歌词；使用其他歌词插件时，等待其加载完成，再切歌或重新播放。词岛自身不搜索歌词，可搭配 [SPW-Lyrics](https://github.com/GaBoron/SPW-Lyrics)。

### 歌名也不对，或者切歌后还停在上一首

切换另一首歌后重试。仍异常时，反馈歌曲类型、SPW 显示是否正确、是否只发生在首次启用，以及再次切歌能否恢复。

### 逐字高亮整体偏早或偏晚

调整“逐字高亮偏移 ms”：正值提前，负值延后。不同歌曲偏差不同时，应检查歌词时间轴。

### 调整播放倍速后明显不同步

等两次播放位置更新后再观察。仍不同步时，反馈倍速、歌词来源、歌曲时间点和 SPW 版本。

### 实验性多行歌词异常

关闭“实验性多行歌词”对比；反馈具体歌曲、歌词来源和出现问题的时间点。

## 封面、进度与频谱

### 看不到专辑封面

确认已授予曲库读取权限。插件可读取 SPW 提供的封面、本地音频内嵌封面，以及同目录的 `cover.jpg`、`cover.png`、`folder.jpg`、`folder.png`。不可访问文件或无封面时显示占位图。

### 开启封面取色后没变化

先确认封面能正常显示。取色会避开近黑和近白区域，结果不一定等同于封面中心颜色。

### 进度条不能拖，或者总时长是 `--:--`

需要可靠的歌曲总时长。网络歌曲、不可读文件或无法解析时长的格式可能不支持拖动，其他播放控制仍可使用。反馈时注明音频格式。

### Windows 实时频谱不动

确认“两侧信息”包含频谱、正在播放且未开启低性能模式。需要 Windows build 20348+、.NET Framework 4.x 和共享模式输出；可将独占模式或 ASIO 切换为共享模式对比。

### 低性能模式下频谱不像真实音乐

低性能模式使用模拟频谱。关闭后可恢复实时捕获。

### Linux 实时频谱显示模拟或不动

确认正在播放、显示频谱且未开启低性能模式。检查 PipeWire 和 PATH 中的 `pw-record` / `pw-dump`，再查看“关于与状态”中的频谱来源。绕过 PipeWire 的输出可能无法捕获。

### Linux 穿透时没有悬停隐藏

X11 和 KDE Wayland 可直接使用；GNOME Wayland 45–50 需先[安装配套支持](installation.md#linux)。在“关于与状态”查看指针连接；需要恢复操作时使用“找回词岛”。

### Wayland 上移开鼠标后控件仍然展开

拖动期间会保持展开，松开并移出后应收起。若持续展开，反馈桌面版本、穿透设置、缩放比例，以及从词岛移到原生 Wayland 窗口的复现步骤。

## 菜单、设置与字体

### Windows 托盘图标启动后短暂出现

图标最终回到隐藏区域时无需处理。持续显示或重复出现时，请导出诊断包并注明 Windows 和 SPW 版本。

### 快捷菜单里找不到某个设置

完整选项在 SPW 插件设置页；运行状态在“关于与状态”。

### 字体异常、缺字或自定义字体效果不对

先切回内置 MiSans 对比。Windows 在“歌词字体”窗口选择；Linux 将字体名称留空。反馈字体名称及缺失的字符。

## 性能

### 液态玻璃未生效或背景更新慢

确认[系统支持](compatibility.md#液态玻璃)、已选择液态玻璃且未开启低性能模式。Linux 首次使用需[安装配套支持](installation.md#linux)。

KDE 系统更新后若提示 KWin 版本不匹配，重新登录桌面。仍异常时，查看“关于与状态”的失败原因，按提示修复并导出诊断包。

### 词岛卡顿或动画不流畅

开启低性能模式对比。反馈系统、SPW 与插件版本、是否开启多行歌词，以及卡顿发生在展开、拖动、切歌还是持续播放期间。

## Linux

### 词岛上右键没有菜单

Linux 使用系统托盘或 SPW 插件设置页。

### 看不到托盘图标

检查桌面的托盘支持；GNOME 通常需要 AppIndicator 扩展。仍可从 SPW 插件设置管理词岛。

### 窗口空白、透明或内容不刷新

先使用“找回词岛”。仍空白时，可在 Steam 的 SPW 启动选项中临时使用软件绘制：

```sh
SPW_ISLAND_RENDERER=software %command%
```

重启 SPW 后对比并导出诊断包，反馈桌面、显卡及驱动版本。移除该参数可恢复默认绘制。

### 拖动松手后短暂闪回原位置

更新插件后重试；仍异常时附录屏、桌面版本、缩放比例和穿透设置。

### 平台专属设置没有效果

查看 [兼容性与限制](compatibility.md)。Linux 暂不支持词岛区域右键菜单和前台全屏自动隐藏。

## 提交 Issue

到 [Issues](https://github.com/GaBoron/SPW-island/issues) 提供系统、SPW 与插件版本、复现步骤、预期和实际表现。歌词问题附歌曲及歌词来源，图形问题附截图或录屏。

在 **SPW 插件设置 → 工具与关于 → 导出诊断包** 生成诊断 ZIP。文件不会自动上传，分享前请检查其中的个人信息。
