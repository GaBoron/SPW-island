# 兼容性与限制

[← 文档首页](README.md)

## 平台

需要 SPW 1.19.0+（Workshop API dev23）和 Java 25+ 的宿主运行环境。

| 平台 | 状态 |
| --- | --- |
| Windows 10 / 11 x64 | 主要支持平台 |
| Linux x64 | 实验性支持 |
| macOS、移动平台 | 不支持 |

## 液态玻璃

- **Windows**：Windows 11 SDR 和 GPU 绘制；作用于词岛、右键菜单和关于页。部分录屏工具可能无法录到玻璃窗口。
- **GNOME Shell 50**：仅词岛主体，需[安装配套支持](installation.md#linux)。
- **KDE Plasma**：Arch Linux、KWin 6.6–6.8 Wayland 和 OpenGL 合成；仅词岛主体，需[安装配套支持](installation.md#linux)。

不满足条件、开启低性能模式或后景不可用时使用经典背景。

## 歌词、封面与播放控制

词岛显示 SPW 已加载的歌词，不负责在线搜索。普通 LRC 可以估算逐字进度，但与实际演唱节奏可能存在偏差；倍速变化后也可能需要后续播放位置回调才能同步。

授权曲库读取后，可从 SPW 获取封面和歌曲总时长；本地文件也可补充这些信息。网络歌曲、无权限文件或无法识别时长的格式，可能无法拖动进度条，但其他播放控制仍可用。

## 实时频谱

频谱仅针对 SPW 及其子进程的播放音频，不采集麦克风或系统混音，也不保存录音。低性能模式或无法捕获时使用模拟频谱。

- **Windows**：需要 Windows build 20348+、.NET Framework 4.x 和共享模式音频输出；独占模式或 ASIO 等输出方式可能无法捕获。
- **Linux**：需要 PipeWire 和 `pw-record` / `pw-dump`；绕过 PipeWire 的播放流可能无法捕获。

可在“关于与状态”中查看当前频谱来源。

## Linux 实验性支持

需要 Linux x64、`/usr/bin/python3` 和 X11 / XWayland；OpenGL 环境不可用时可能回退到兼容绘制。

悬停隐藏支持 X11、KDE Wayland 和安装配套扩展的 GNOME Wayland 45–50；其他 Wayland 桌面暂不支持该功能。Linux 暂不支持词岛区域右键菜单、前台全屏自动隐藏和 Windows 额外置顶强化。

不同桌面下托盘、窗口位置或缩放可能有差异。安装方式见 [安装与更新](installation.md)，遇到问题请查看 [故障排查](troubleshooting.md)。
